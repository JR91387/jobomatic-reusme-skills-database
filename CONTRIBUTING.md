# Contributing

Improvements and collaboration are welcome.

1. Open an issue first. Say what you want to fix or add.
2. Fork, make a branch, and open a pull request that links the issue.
3. Run the tests: `pip install -r requirements.txt` then `python -m unittest`.
4. Changed the schema or the MCP tools? Run `python scripts/gen_wiki.py` so the wiki stays in sync.

Keep changes small and focused. Use the made-up demo data only, never real personal data.

More detail: [For Developers](https://github.com/JR91387/jobomatic-reusme-skills-database/wiki/For-Developers).
