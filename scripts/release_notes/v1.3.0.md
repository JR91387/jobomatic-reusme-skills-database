## What's new
- **Faster.** Database schema v6 adds indexes for the lookups the app and your AI make most. A v5 database upgrades itself on first start, after an automatic backup.
- **Safer local helper.** Your data and original files are served only to the page the app opened (a per-start key), other sites can't frame the app, and adding an original checks the file first.
- **Update from the app.** "Update now" backs up your database first. pip, uv and pipx installs then update and restart by themselves. Zips download the new version, check its checksum, and swap it in on restart; if the new version doesn't start, the previous one comes back. Your `my_data/` folder is never touched. After an update, restart your AI app so it picks up the new MCP server.
- **Fixes in the app.** Fixes from user testing in the forms, résumé templates and edit mode.
- **Build.** Portable Python is checked against digests pinned in the source, and bundled packages are installed only with matching hashes.
